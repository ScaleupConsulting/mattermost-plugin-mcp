# MCP Server (com.scaleupconsulting.mcp)

A remote MCP server inside Mattermost, so Claude (a claude.ai custom connector, Claude Desktop or Claude Code) and other MCP clients can read and, if allowed, post in Mattermost as the signed-in user. Requires Mattermost 12.0+. It needs no Enterprise licence and does not use Mattermost's own OAuth service provider.

Work in progress: see the full README once the first version lands.
